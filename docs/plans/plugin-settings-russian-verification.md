# Русская обвязка настроек плагинов

Дата: 24 ноября 2026. Основа: слитый PR #26, `f28abe1a527f2c59763dfa5e16fe849f95d8e628`. Проверенные исходники: `a4878b1846ad907516784c33ae47e7dd661b0afc`; последующие изменения — документация.

## Изменение

Общая страница настроек плагина переводит заголовок Configuration, ссылку Plugin details, доступные имена включения/отключения, загрузочное состояние, сообщения недоступности, пустые подсказки выбора, отметку secret и состояния сохранённого ключа. Локальная проверка числа и уведомление о неудачном сохранении используют язык интерфейса. Значение внутреннего статуса в сообщении недоступности передаётся буквально.

Названия, описания, подписи, варианты выбора и значения, присланные плагином, остаются исходными. Раньше общий SettingsWithControl переводил подписи и описания, даже если они принадлежали внешнему плагину: описание `Queue` становилось «Добавить в очередь». Теперь PluginSettings отключает перевод этих данных, сохраняя прежние текстовые anchors. Остальные встроенные строки SettingsWithControl продолжают переводиться.

Локальная ошибка числа отличается по типу от внешней ошибки. Это позволяет менять её язык при открытом поле, сохраняя буквально такую же строку `Enter a finite number`, пришедшую от сервера плагина. Уведомление получает локализованный контекст операции через существующие mutation metadata. Глобальное поведение уведомлений не заменено.

Ключи и значения сохранения, маршруты, разрешения, маскировка секретов и доступность CLI/SDK не меняются. Используется прежняя настройка `interfaceLanguage`, включая `bb settings general interfaceLanguage ru`. Новых настроек, публичных SDK members, миграций и wire fields нет; SDK **0.6.180**, протокол **283**.
