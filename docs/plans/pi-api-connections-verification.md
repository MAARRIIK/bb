# Подключения API через Pi

Дата: 24 ноября 2026. Основа: слитый PR #25, `ff82f8c68a66f3ac12c034bb2072962f78a2d4f9`. Проверенные исходники: `89e8565bf33b8f6824a71f15d7d063d03883438f`; дальнейшие изменения — документация.

## Поведение

Настройки плагина Pi содержат панель «Подключения API»: Gemini, Kimi / Moonshot AI, **GLM / Z.ai Coding Plan** и DeepSeek. Значения сохраняются в существующее зашифрованное окружение BB, глобально или для выбранного проекта. Можно заменить ключ или удалить сохранённое значение; удаление значения проекта возвращает наследование общего ключа. После сохранения и смены сервиса/области поле очищается. Во время записи выбор области и повторная отправка заблокированы; ошибка допускает повтор и не отображает текст исключения, который мог бы содержать ключ.

Панель использует браузерный `useSdk()` и существующие system/project environment methods, сохраняя авторизацию штатного маршрута. Backend плагина не выполняет запись ключей от имени вызывающего клиента. Ключи не записываются в native auth/models файлы Pi. Данные входа, уже сохранённые самим Pi, имеют приоритет над окружением; панель явно сообщает об этом. Сохранение не проверяет доступ к API и не отправляет платный запрос.

`bb pi api-providers --json` и discoverable RPC `api-providers.list` возвращают только метаданные пресетов и ссылки на официальные инструкции. Запись через CLI использует существующий `bb machine env set NAME`, читающий значение из stdin; SDK использует тот же серверный владелец окружения. Команды, SDK, область действия и приоритет native credentials описаны в навыке Pi и `docs/configuration.md`.

Для плагинов добавлен `experimental_useInterfaceLanguage(): "en" | "ru"`. Он использует тот же контекст, что и основной переводчик BB. Панель Pi предоставляет собственные строки и реагирует на изменение языка без отдельной настройки. SDK и каноническая версия совместимости — **0.6.180**; Pi требует эту версию, чтобы старый хост не загружал неподдерживаемый frontend. Добавлены запись аудита API и описание в существующей карточке Plugin Guide. Миграции и daemon wire fields не требуются; протокол остаётся **283**.

## Настоящая сборка

Использованы отдельные checkout, база с маркером владельца, временный Git-проект и браузерный профиль. Pi запущен через абсолютные Node/Pi paths и отдельный agent-dir с пустым auth.json. Пользовательская конфигурация Pi не изменялась.

1. Настройки открыты обычной навигацией. Через UI сохранены четыре явно вымышленных общих ключа. После каждого сохранения поле пустое; CLI возвращает только имена, `secret: true` и `value: null`.
2. У проекта показано наследование DeepSeek. UI сохранил отдельный ключ проекта, CLI подтвердил единственную отдельную переменную. После перезагрузки и выбора проекта значение осталось сохранённым; удаление через UI вернуло наследование и пустой список отдельных значений.
3. В другой вкладке настоящим нажатием выбран English. Уже открытая панель обновилась, сохранив сервис, проект и несохранённый черновик. CLI подтвердил en. Возврат ru через CLI обновил ту же панель и сохранил черновик; затем поле очищено вручную.
4. На **390×844** панель помещается по ширине, поле и действия доступны, документ шириной 390; корень не inert/aria-hidden. Просмотрены скриншоты русского и английского desktop и русского compact.
5. Настоящий SDK выполнил чтение нового RPC, запись, маскированное чтение и удаление отдельного ключа Gemini проекта. Метаданные RPC совпали с CLI; после удаления сохранилось наследование.
6. В SQLite обнаружены четыре общих API-ключа в `environment_variables`, версия шифрования 2; столбец ciphertext не содержит вымышленные исходные значения. В QA-базе **0 `client/turn/requested`**. Настоящий Pi через BB вернул модели google (22), moonshotai (10), zai (7), deepseek (3) с положительными объявленными context windows. Это обнаружение конфигурации, не проверка удалённой авторизации или фактического окна модели.
7. В собранном Plugin Guide открыта карточка Custom settings section, раскрыто API behavior и прочитано описание нового hook. Нажатие Copy for agent выполнено, но headless-браузер не разрешил чтение clipboard: результат содержимого буфера не считается проверенным.

Свидетельства: `.tmp/verify-pi-api-20261124/`, включая `final-summary.json`, `storage-catalog-summary.json`, `sdk-proof.json`, `native-models.json`, маскированные CLI readbacks и просмотренные изображения. Сырые материалы не включены в Git. Вымышленные ключи удалены; браузер и launcher остановлены. После проверки маркера и принадлежности процессов все пять портов свободны, собственная база и чистый временный Git-проект удалены.

## Оставшиеся проверки

Выполнение запросов и работа с файлами через реальные аккаунты этих четырёх API требуют пользовательских ключей и не проверены этим этапом. Существующий путь Pi/Qwen и работа с файлами проверялись раньше; это не заменяет проверку конкретных облачных моделей. GLM pay-as-you-go endpoint, Kimi Coding, собственный совместимый сервер и браузерный DeepSeek не входят в эти четыре пресета. Нативные iOS Safari, Linux, Android и VPS здесь не проверены. Некоторые заголовки общей страницы плагина остаются на английском и требуют следующего этапа локализации.
