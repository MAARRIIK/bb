# Русские основные настройки и оформление

Ветка: `personal/settings-russian`, основа `212850c441b48365ea09413da35e3e2348968fec` — слитый PR #1.

## Изменения

Расширен словарь встроенных текстов основных настроек и оформления: пояснения, проверки префикса веток, поведение Enter, цвета, выбор встроенной навигации, нижняя часть боковой панели, ссылки приложений, установка CLI и навыков, настройки микрофона. Переведены подписи элементов управления и названия мобильных выдвижных меню для систем доступности.

Переводчик поддерживает именованные подстановки. Сначала выбирается текст интерфейса, затем в него один раз подставляются исходные значения. Пути, адреса, названия устройств и машин, пользовательские палитры и тексты сторонних плагинов сохраняются буквально. Встроенные названия и пояснения переводятся отдельно. Данные с `{source}` или `$&` не проходят повторную обработку. Для неизвестных текстов остаётся английский вариант.

Используются существующие настройки UI, SDK и CLI; новых команд, параметров, миграций или полей протокола server/daemon нет. Другие страницы и интерфейсы плагинов ещё требуют перевода.

## Проверка

Среда: macOS arm64, Node 22.19.0, pnpm 9.15.0, отдельный `pnpm dev` с новой базой. Исходная база установленного приложения не использовалась.

| Проверка | Результат |
| --- | --- |
| Turbo lint/typecheck и build для `@bb/app` | Пройдены |
| Целевые тесты настроек, поиска, палитр, микрофонов, CLI, переводчика и подстановок | Пройдены; 99 разных тестовых случаев, последние изменения меню перепроверены отдельно |
| Названия и описания сторонних плагинов `Settings` / `Dark` в en и ru | Проверены тестом на настоящих компонентах |
| Chromium: русские пояснения и поведение Enter, сохранение через UI и чтение CLI | Пройдено |
| Префикс `Settings/{source}/$&/`, сообщение о недопустимом префиксе | Проверены через UI и сохранённое серверное значение |
| Цвет значка после перезагрузки, русские пункты навигации и сохранённый `navigation/top-list` | Проверены через UI и CLI |
| Узкий сенсорный экран 390 × 844 и окно установки навыков | Проверены; установка не запускалась |
| Мобильная панель микрофона и сообщение об отказе в доступе | Проверены; звуковая запись не выполнялась, корень приложения не получил inert/aria-hidden |
| iOS Simulator Safari | Недоступен: установлен Command Line Tools, утилиты `simctl` нет |
| Linux и нативные приложения | Не запускались |

Проверка ограничена переводом затронутых поверхностей и сохранением их существующего поведения. Она не подтверждает полную локализацию IDE, запись/транскрибацию голоса или работу всех провайдеров. Карта verify-bb дополнена целевым рецептом; её общее исходное расхождение владельца CLI `diagnostics` остаётся отдельной задачей.

Локальные журналы и снимки находятся в игнорируемых `.tmp/verify-settings-russian/` и `.tmp/toolchain/`.
