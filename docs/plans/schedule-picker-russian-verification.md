## Изменение

Общий ScheduleTimeFields и его словарь используются окном изменения времени задания и плагином Send later. Русский и английский покрывают варианты расписания, поля даты и времени, предпросмотр, часовой пояс, кнопки, доступное имя закрытия, локальную проверку и уведомление об успехе. Плагин получает язык через существующий `experimental_useInterfaceLanguage`, core — через тот же источник настроек. Смена языка не пересоздаёт форму.

Идентификаторы вариантов и расчёт момента отправки не меняются. Форматирование использует выбранную локаль. Ошибка разбора сохраняет прежние строковые значения, уточнённые типом. Новый тип состояния ошибки различает собственную проверку и внешнюю ошибку запроса: внешняя строка остаётся буквальной, даже если совпадает с текстом встроенной проверки. Старые строковые props общего компонента принимаются буквально; язык по умолчанию английский. DialogContent принимает необязательную подпись закрытия с прежним английским значением по умолчанию.

Используются существующие queue update и composer submit, SDK и CLI. Настройка остаётся `bb settings general interfaceLanguage ru`; новых настроек, маршрутов, CLI flags, публичных Plugin SDK members и wire fields нет. SDK **0.6.180**, протокол **283**. Send later требует SDK не ниже 0.6.180. Три registry item пересобраны штатным генератором. Документация плагина и рецепт QA исправляют прежнее неверное указание на плюс: действие находится в Send options рядом с Submit.
