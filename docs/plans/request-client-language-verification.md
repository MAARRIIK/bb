## Поведение

Браузер отправляет `x-bb-client-language: en|ru`. SDK принимает `clientLanguage`
в create/fork/send/queued create: значение тела имеет приоритет над заголовком,
`null` запрещает наследование, отсутствие использует заголовок и затем язык
последнего запроса исходного диалога. При прямой отправке без исходного диалога
используется целевой диалог. Неподдерживаемые значения отклоняются на HTTP boundary.

Обычный CLI использует `LC_ALL`, затем `LC_MESSAGES`, затем `LANG`, с тем же
разрешением поддерживаемых языков и английским fallback, что и интерфейс.
CLI агента с caller thread не использует локаль машины: язык наследуется от
исходного диалога. Сервер не выводит язык устройства из своей ОС.

Язык сохраняется при принятии запроса, постановке в очередь, повторе, запуске и
восстановлении provisioning. Редактирование текста, времени, модели и зависимостей
очереди не меняет происхождение задания. Группировка требует одинаковых языковых
подсказок. Старые задания остаются с неизвестным языком и не заимствуют его у
позднего клиента. Ручные общие настройки применяются при запуске и имеют приоритет;
явное указание пользователя в тексте имеет приоритет над предпочтением модели.
Сохранённый пользовательский текст не переписывается.

Добавлен nullable `queued_thread_messages.client_language`; миграция
`0173_thankful_gladiator.sql` и snapshot созданы штатным генератором Drizzle.
Протокол daemon повышен с 283 до 284, поскольку метаданные входят в общий wire
контракт событий. Новых публичных методов Plugin SDK нет.
