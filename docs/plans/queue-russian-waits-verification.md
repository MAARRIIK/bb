# Язык ожиданий и времени отправки

Дата: 24 ноября 2026. Основа: слитый PR #23, `989ff45f4357e503a995747f1145dc5a60076dec`. Проверенные исходники: `d6267c15e1b22bd5cad5f50a2c72c728eac1edf4`; последующие изменения — только документация.

## Изменение

Встроенные причины ожидания, описание повторов и продолжения после перезапуска, даты отправки и обратный отсчёт следуют выбранному языку интерфейса. Русский вариант показывает, например, «Отправка: 17:27», «Отправка: Завтра 16:27», «через 59 мин». Английский использует выбранную английскую локаль: `5:27 PM`, `Tomorrow 4:27 PM`, `in 59m`. Часовой пояс остаётся местным для клиента.

Ранее часы и даты брались из системной локали процесса: русский интерфейс мог показывать `11:30 PM`. Форматтер времени теперь требует разрешённую локаль en/ru. Её передают все вызывающие компоненты, включая загрузочный вариант очереди, заголовок повтора, свёрнутую сводку и строки заданий. Календарное вычисление «завтра» сохранено, включая дни продолжительностью 23 и 25 часов.

Перевод ожидания зависимости перенесён из отдельной ветки компонента в общий форматтер. Сохранён прежний приоритет UI: ожидание зависимости отображается раньше предыдущего описания ошибки. Правила допуска и ручной отправки не меняются.

Переводятся только встроенные шаблоны. Ошибки провайдеров, причины ожидания плагинов, причина повтора от плагина, имена машин, отправителей и ID передаются буквально. Известный встроенный текст внутри чужой ошибки тоже остаётся исходным текстом. Подстановки с `{time}` и `$&` не обрабатываются повторно.

Новых настроек, SDK members, CLI-флагов, миграций или daemon wire fields нет; протокол **283**. UI, существующая команда `bb settings general interfaceLanguage ru` и SDK `system.updateGeneralSettings` по-прежнему используют общую настройку.

## Ограничения

Окно выбора расписания, некоторые элементы редактора, остальная IDE и тексты плагинов ещё требуют перевода. Это изменение не переводит внешние сообщения ошибок и не добавляет язык ответов ИИ. Нативная смена часового пояса/DST в браузере не выполнялась: календарные границы проверены автоматическими тестами. Safari/iPhone, Linux, Android и VPS не проверены.
