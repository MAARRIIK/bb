# Проверки кэша переключения и загрузки очереди

Дата: 24 ноября 2026. Основа: `3eab346b7881d4510e79fbb161251873b6db3c59`, основная ветка после PR #24.

Полный прогон приложения при подготовке подключений Pi выявил два независимых падения. Они повторены отдельно на неизменённых исходниках основной ветки: **2 failed, 80 passed**. Лог: `.tmp/toolchain/test-cache-queue-baseline.log`.

Первое падение — шесть прямых записей и обновлений кэша внутри `ThreadProviderSwitch`. Они нарушали существующую границу: изменения кэша должны принадлежать `hooks/cache-owners`. Запись ID операции, принятие результата с обновлением диалога и параметров выполнения, повторное чтение после обрыва теперь проходят через отдельный модуль владельца кэша. Чтение и запись используют общие фабрики ключей. Значения ключей, порядок действий, сохранение ID в localStorage и серверные операции сохранены.

Второе падение — тест загрузочного состояния ожидал строку `Queue1`, хотя заголовок был переименован в `Message queue` при разделении названия очереди и действия добавления. Тест теперь отдельно проверяет доступный контейнер, актуальный заголовок и счётчик, сохраняя проверку статуса загрузки.

После исправления через Turbo выполнены три файла: проверка границ кэша, `ThreadDetailPromptArea` и сценарии `ThreadProviderSwitch`: **88 passed**. Проверены блокировка второго окна при незавершённой операции, выбранная модель, явные разрешения, восстановление после перезагрузки без второго commit и компактный drawer. Лог: `.tmp/toolchain/test-cache-queue-fixed.log`.

Сборка, типизация и lint приложения выполнены через Turbo: **8 successful tasks**; лог `.tmp/toolchain/build-check-cache-queue.log`. Сборка завершилась успешно с предупреждениями о крупных чанках и недоступной записи одного файла кэша React Compiler в защищённый `.git`; эти предупреждения не выдаются за ошибки тестов. Новых API, CLI-флагов, настроек, миграций или полей протокола нет. Протокол исполнителя остаётся **283**.

Изменение проверено по `docs/CODE_REVIEW.md` и навыку deslop. Новые тестовые обёртки или тесты тривиальных функций не добавлены. Полный прогон приложения до исправления не считается успешным; итоговый общий прогон выполняется при следующем этапе подключений.
