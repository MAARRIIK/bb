# Give BB a Codex-style appearance

Codex Theme adds two appearances under **Settings → Appearance**: **Codex**, with Catppuccin colors, and **Codex (BB colors)**, which keeps BB's default colors. Both use Codex-inspired typography, a compact composer, a roomier navigation rail, rounded menus and notifications, and a matching code palette.

Install the plugin to add the themes. When installed while BB's default theme is selected, it activates Codex; an existing theme choice is left in place. Select either Codex palette in Appearance whenever you want to switch. Plugin settings can turn on optional layout changes such as a centered new-thread welcome, a left-side thread outline, or alternate thread indicators.
